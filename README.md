## About

I build mobile apps and the infrastructure behind them. Most of my work sits at the intersection of realtime systems and mobile delivery — multiplayer game backends, over-the-air update pipelines, and social apps that need low-latency feeds.

- Working with **Flutter**, **Kotlin**, **React Native**, **TypeScript**, **Rust**
- Interested in realtime netcode, OTA update delivery, and self-hosted developer tooling
- Currently learning Rust to push deeper into the systems side
